🚀 Img2XL – AI-Powered Image to Structured Data Converter

Img2XL is a full-stack AI application that converts images (tables, receipts, documents) into clean, structured data formats like JSON or Excel-ready output.

It leverages modern AI APIs and data processing techniques to automate extraction and cleaning of information from images.

⚙️ How It Works
User uploads an image
Image is processed using AI APIs
Extracted text is parsed into structured format
Data cleaning logic refines output
Final structured data is returned to user
🧪 Installation & Setup
# Clone the repository
git clone https://github.com/tiru-venkatesh/img2xl.git

# Navigate to project folder
cd img2xl

# Install dependencies
npm install

# Start the server
node index.js
🔐 Environment Variables

Create a .env file in the root directory:

API_KEY=your_api_key_here
PORT=4000
