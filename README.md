# DocuMind AI (Img2XL)

## Overview

DocuMind AI is an AI-powered document intelligence system that converts unstructured documents into structured, usable data.

## Features

* Image enhancement
* OCR text extraction
* Intelligent chunking
* Structured output (JSON / clean text)

## Tech Stack

* React.js
* Node.js
* AI APIs (Gemini / OCR)

## Use Cases

* Notes digitization
* Invoice processing
* Document automation
